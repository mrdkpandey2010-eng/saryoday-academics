
2. डिपेंडेंसीज इंस्टॉल करें (यदि पहले से न हों):

## ☁️ गिटहब (GitHub Pages) पर 100% मुफ़्त होस्टिंग (Free Hosting on GitHub)

यह वेबसाइट पूर्णतः क्लाइंट-साइड एसपीए (Single Page Application) है जिसे गिटहब पेजेस पर मुफ़्त होस्ट किया जा सकता है।

### विकल्प A: GitHub Actions द्वारा ऑटोमैटिक डिप्लॉय (सबसे आसान)
1. अपने गिटहब खाते पर एक नया रिपॉजिटरी बनाएं (उदा. `saryoday-academics`)।
2. लोकल कोड को गिटहब पर पुश करें:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Saryoday Academics Coaching Website"
   git branch -M main
   git remote add origin https://github.com/<आपका-यूजरनेम>/saryoday-academics.git
   git push -u origin main
   ```
3. गिटहब रिपॉजिटरी की **Settings** > **Pages** में जाएं:
   - **Build and deployment** > **Source** में **GitHub Actions** चुनें।
4. `.github/workflows/deploy.yml` पहले से तैयार है; आपका प्रोजेक्ट अपने आप बिल्ड होकर कुछ ही सेकंड में लाइव हो जाएगा!

### विकल्प B: `npm run deploy` द्वारा 1-क्लिक में डिप्लॉय
`package.json` में `gh-pages` पहले से कंफिगर है:
```bash
npm run deploy
```
